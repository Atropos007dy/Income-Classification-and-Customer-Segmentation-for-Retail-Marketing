# Income Classification and Customer Segmentation for Retail Marketing

## Overview

This project completes two modeling tasks for a retail marketing use case:

1. **Income Classification**: Build a supervised model to predict whether an individual belongs to the higher-income group.
2. **Customer Segmentation**: Build an unsupervised segmentation model to group individuals into interpretable marketing segments.

The final report is included in the repository as `report.pdf`.

## Setup

This project was developed with Python 3.13. A virtual environment is recommended.

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On macOS, XGBoost may require the OpenMP runtime. If importing xgboost fails with a libomp.dylib error, install libomp with Homebrew:
brew install libomp
Then verify XGBoost:
python -c "from xgboost import XGBClassifier; print('xgboost ok')"

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

data_processed/cleaned_dataset.csv
data_processed/onehot_dataset.csv

How to Run the Code

Run all commands from the repository root.

1. Data Exploration
python data_exploration/eda.py

This script generates column-level summaries and exploratory plots.

Main outputs:

data_exploration/column_summary.csv
outputs/figures/eda/

2. Data Preprocessing
python data_exploration/preprocess_data.py

This script performs missing-value handling, target encoding, binary feature encoding, and one-hot encoding.

Main outputs:

data_processed/cleaned_dataset.csv
data_processed/onehot_dataset.csv

3. Train XGBoost Models
python src/train_xgboost.py

This script trains XGBoost models over a hyperparameter grid, evaluates validation metrics, tunes classification thresholds, and saves model outputs.

Main outputs:

outputs/models/
outputs/metrics/
outputs/thresholds/
outputs/model_comparison.csv

4. Select Final XGBoost Model and Evaluate on Test Set
python src/select_best_xgboost.py

This script loads the saved XGBoost models, evaluates validation thresholds, selects the final model and decision threshold, and evaluates the selected model on the held-out test set.

Main outputs:

outputs/best_model_selection.csv
outputs/best_model_selection_by_auc.csv
outputs/best_model_selection_by_f1.csv
outputs/best_model_test_metrics.json
outputs/best_xgboost_model_273.json

5. Run Customer Segmentation
python src/segmentation.py

This script runs KMeans customer segmentation using selected marketing-relevant features. It compares candidate values of k, fits the final segmentation model, and saves segment profiles and visualizations.

Main outputs:

outputs/segmentation/k_selection.csv
outputs/segmentation/segmented_dataset.csv
outputs/segmentation/cluster_numeric_profile.csv
outputs/segmentation/cluster_2d_plot.png
